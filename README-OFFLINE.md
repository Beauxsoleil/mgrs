# Offline MGRS Planner

Deploy all files together at the HTTPS root of your site. Open once online, then use **Save area** while online to cache terrain and USGS basemap tiles for your intended route. Install to iPhone Home Screen. Start GPS, grant location permission, and test in airplane mode before field use.

GPS comes from iPhone location services (works without cellular reception when a satellite fix is available). The first-generation Garmin Instinct Solar does not provide a supported live GPS feed directly to Safari. Garmin GPX files can be imported for recorded tracks. Garmin LiveTrack depends on phone connectivity and is not an offline substitute.

Offline tiles are limited to downloaded regions and zoom levels. iOS may evict caches; recheck before travel. Do not rely on this experimental map as your only navigation method.
